# Planned/connected business modules

Orders: Received → File Checking → Designing → Proof Sent → Customer Approved → Prepress → Plate → Printing → Finishing → Quality Check → Ready → Delivered.

Payments: eSewa, Khalti, bank transfer, card gateway, cash; 25/50/100% advance; partial balance; verification; receipt; refund.

ID cards: school/employee fields, photo, template, QR/barcode, bulk Excel import, proof approval, Excel + Photos ZIP export.

Inventory: paper/GSM, sheets, ink, toner, lamination, binding materials, packaging; purchase/use/adjustment/current/low-stock.

Reports: sales, purchases, expenses, profit/loss, outstanding, customer/product sales, stock, tax/VAT, ID-card reports.

Roles: Super Admin, Admin, Designer, Production Staff, Accountant, Customer.

Security: server-side GitHub token, role-based authorization, audit log, backups, password hashing and production authentication should be completed before exposing admin publicly.
